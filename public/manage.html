Jellyfin

Jellyfin connection

Jellyfin must be running on your media server. MyMusics connects from this server to Jellyfin.

Checking

Use the address reachable from UbuntuMedia. If Jellyfin runs on the same machine with Docker port 8096 published, use http://127.0.0.1:8096. You can paste the Jellyfin web address; `/web/#/login` will be removed.

Create a key in Jellyfin under Dashboard → API Keys. The saved key is stored on the MyMusics server and is never sent back to this page. Use this form only on a trusted network; MyMusics currently uses HTTP.
