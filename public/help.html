MYMUSICS GUIDE

How to use MyMusics

Step-by-step help for playback, lyrics, volume controls, stations, and genres.

ListenFavoritesLyrics Audio toolsStationsGenresUpdates

01 · PLAYBACK

Listen to a station

  1. Choose a genre in the sidebar, or choose Favorites.
  2. Select the play button beside a station. Use the browser audio controls to pause, resume, seek when supported, or adjust playback volume.
  3. Track details, artwork, and lyrics appear below the player when the stream and lookup services provide them.

Use Search stations above the list to filter the selected genre or Favorites by station name.

Use Hide controls to collapse the extra player tools. Select Show controls to open them again.

02 · YOUR SHORTLIST

Manage Favorites

Select the star beside a station on Listen or the Favorite button on Manage to add it to Favorites; select it again to remove it. Open Favorites in the Listen sidebar to see the shortlist. A favorite remains in its regular genre too.

03 · TRACK LYRICS

Show and sync lyrics

  • Lyrics load automatically when a track is identified and a match is available. Plain lyrics are shown as text; synchronized lyrics highlight and scroll with the song.
  • For synchronized lyrics, select a lyric line to align the lyric highlight from that point. This does not seek or change the audio.
  • Use − to show lines later and + to show them earlier. Each click adjusts timing by 250 ms, within a range of 0 to 3 seconds; the value between the buttons shows the current delay. The initial delay is 300 ms.
  • The indicator beside Lyrics is green when the stream sends a track start time and red when it does not. Without a start time, synchronization uses when MyMusics began playback.

Lyrics and timing data depend on third-party matches. Some tracks have no lyrics or only unsynchronized lyrics.

04 · SOUND

Equalizer and automatic volume

Equalizer

  1. Start a station, open the player tools, and select Equalizer.
  2. Choose a preset or adjust the frequency sliders. Select EQ On to apply the settings; use Reset to return to Flat.

Some streams block browser audio analysis. The equalizer may be unavailable for those streams, but playback continues normally.

Suppress ads / speech

On compatible MP3 streams, speech detection starts automatically during playback unless you have turned it off for that station. MyMusics gradually lowers the station volume to its configured target when it detects speech, then gradually restores the playback volume. Select Keep normal volume for this track when a song contains speech that should not be suppressed. That exception is saved in this browser for the artist and title. Use Suppress ads / speech to turn detection off or back on for a station. HLS streams do not support speech detection; some MP3 providers also block the audio analysis it needs.

Set the target percentage with the Speech / ad volume field when adding or editing a station in Manage, or use the percentage button in the player tools while it is playing. The setting is saved for that station.

05 · STATION LIBRARY

Add and edit stations

Quick edit from Listen

  1. Select Edit above the station list. An Edit button appears on each station.
  2. Open a station to change its name, stream URL, stream type, or genre, then select Save changes. Choose Delete station to remove it after confirming.
  3. Select Done above the list to leave edit mode.

Add or fully edit from Manage

  1. Open Manage in the sidebar and select a genre.
  2. Select Add station, enter a name and stream URL, and choose MP3 or HLS. Filter the station list by name, or use Find and preview streams beside the URL to search by station name, listen to up to 10 candidates, and fill in the chosen stream. HLS URLs must end in `.m3u8`. If you omit `https://` or `http://`, MyMusics adds HTTPS.
  3. Set the speech/ad target volume if desired, then save. Use each station's Edit action to change its URL, type, name, genre, or target volume.
  4. Optionally upload a PNG, JPEG, or WebP station logo (up to 2 MB). The image is stored locally and removed automatically when no station uses it.

Find stations by music and country

In Manage, optionally enter a two-letter country code such as NL, US, GB, or ES. Leave it blank to search worldwide by music tag or station name (for example, golden oldies). With a country selected, leave the style blank or enter all to search every style there. Results are added to the matching genre. Results may include streams that later become unavailable.

Station changes are stored in `stations.json` and survive a server restart.

06 · ORGANIZATION

Create, rename, or delete genres

  1. Open Manage. Use New genre name and the plus button to add a genre.
  2. Select a genre in the sidebar or the genre picker. Edit its name and select Save name.
  3. Select Delete genre and confirm to delete it. Deleting a genre also deletes all stations in it.

07 · APP UPDATES

Check and install an update

Open Manage to see the installed version and code build date. MyMusics checks GitHub for a newer release when the page opens; select Check to check again. On a server with the updater service installed, select Install and restart to download the release. The app restarts and radio playback may stop briefly. Station settings and logos remain in persistent storage.

TROUBLESHOOTING

Playback works, but a tool does not?

Radio playback and optional analysis are separate. If a stream blocks audio analysis, the equalizer or speech detection may be unavailable while playback still works. Track details, artwork, and lyrics also depend on metadata being sent and external services being reachable.
