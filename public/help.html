MYMUSICS GUIDE

How to use MyMusics

Help for Radio, Music, YouTube, audio output, playlists, and library management.

01 · PLAYBACK

Listen to a station

  1. Choose a genre in the sidebar, or choose Favorites.
  2. Select the play button beside a station. Use the play/pause button and Volume slider below the track details to control playback.
  3. Track details, artwork, and lyrics appear below the player when the stream and lookup services provide them.

Select Search above the player to search all saved radio stations, across genres. Select a result to play it.

Select Sound settings to show the equalizer and speech/ad controls, and Close sound settings to hide them.

02 · YOUR SHORTLIST

Manage Favorites

Select the star beside a station on Radio or the Favorite button in Management to add it to Favorites; select it again to remove it. Open Favorites in the Radio sidebar to see the shortlist. A favorite remains in its regular genre too.

03 · TRACK LYRICS

Show and sync lyrics

  • Lyrics load automatically when a track is identified and a match is available. Plain lyrics are shown as text; synchronized lyrics highlight and scroll with the song.
  • For synchronized lyrics, select a lyric line to align the lyric highlight from that point. This does not seek or change the audio.
  • Use − to show lines later and + to show them earlier. Each click adjusts timing by 50 ms, within a range of 0 to 3 seconds; the value between the buttons shows the current delay. The initial delay is 300 ms.
  • The indicator beside Lyrics is green when the stream sends a track start time and red when it does not. Without a start time, synchronization uses when MyMusics began playback.

Lyrics and timing data depend on third-party matches. Some tracks have no lyrics or only unsynchronized lyrics.

04 · SOUND

Equalizer and automatic volume

Equalizer

  1. Start a station, open Sound settings, and select Equalizer.
  2. Choose a preset or adjust the frequency sliders. Select the EQ Off power button to enable the equalizer; it changes to EQ On; use Reset to return to Flat.

Some streams block browser audio analysis. The equalizer may be unavailable for those streams, but playback continues normally.

Suppress ads / speech

On compatible MP3 streams, speech detection starts automatically during playback unless you have turned it off for that station. MyMusics gradually lowers the station volume to its configured target when it detects speech, then gradually restores the playback volume. Identified songs normally keep their volume unless you enable Suppress this track. Select Stop suppressing this track to undo that choice. When feedback appears, use Yes, suppress or No, keep volume. Track choices are saved in this browser for the artist and title. Use Suppress ads / speech to turn detection off or back on for a station. HLS streams do not support speech detection; some MP3 providers also block the audio analysis it needs.

Set the target percentage with the Speech / ad volume field when adding or editing a station in Manage, or use the percentage button in the player tools while it is playing. The setting is saved for that station.

05 · STATION LIBRARY

Add and edit stations

Quick edit from Radio

  1. Select Edit above the station list. An Edit button appears on each station.
  2. Open a station to change its name, stream URL, stream type, or genre, then select Save changes. Choose Delete station to remove it after confirming.
  3. Select Done above the list to leave edit mode.

Add or fully edit from Manage

  1. Open Manage in the sidebar and select a genre.
  2. Select New station to open the editor, enter a name and stream URL, and choose MP3 or HLS. Filter the station list by name, or use Search and preview streams beside the URL to search by station name, listen to up to 10 candidates, and fill in the chosen stream. HLS URLs must end in `.m3u8`. If you omit `https://` or `http://`, MyMusics adds HTTPS.
  3. Set the speech/ad target volume if desired, then save. Use each station's Edit action to change its URL, type, name, genre, or target volume.
  4. Upload a PNG, JPEG, or WebP logo, select Find logo automatically, or enter a logo URL and select Use image URL. Logos are optimized to WebP (up to 512 pixels) and copied to this server. Save the station to keep the logo. Use Fetch missing logos in the genre view to find logos for multiple stations.

Find stations by music and country

In Manage, optionally enter a two-letter country code such as NL, US, GB, or ES. Leave it blank to search worldwide by music tag or station name (for example, golden oldies). With a country selected, leave the style blank or enter all to search every style there. Results are added to the matching genre. Results may include streams that later become unavailable.

Saved stations and logos survive a server restart.

06 · ORGANIZATION

Create, rename, or delete genres

  1. Open Manage. Use the Add genre field and the plus button to add a genre.
  2. Select a genre in the sidebar or the genre picker. Edit its name and select Save name.
  3. Open Danger zone, select Delete genre, and type the genre name to confirm. Deleting a genre also deletes all stations in it.

07 · APP UPDATES

Check and install an update

Open Manage to see the installed version and code build date. MyMusics checks GitHub for a newer release when the page opens; open Version and updates and select Check for updates to check again. On a server with the updater service installed, select Install and restart to download the release. The app restarts and radio playback may stop briefly. Station settings and logos remain in persistent storage.

08 · MUSIC LIBRARY

Play music from Jellyfin

  1. In Management · API connections, enter your Jellyfin server URL and API key, optionally a user ID, then select Save settings and Test connection.
  2. Open Music. Use Refresh library to update the library after changes in Jellyfin.
  3. Select Browse music to search artists, albums, tracks, genres, or playlists and add music to the queue.
  4. Use Play, Pause, and Play next below the player. The deck sliders seek within loaded tracks; the Volume slider controls music volume.

Use AutoDJ to choose an artist, album, or genre as a source for continued playback. Crossfade controls the overlap between automatic track transitions; Natural outro saves a fade-out duration for a track where that control is available.

Music also provides lyrics and Sound settings. In Management, Music genres groups library labels under display names without changing Jellyfin metadata.

09 · VIDEO

Watch and queue YouTube videos

  1. Open YouTube and paste a video link into Load YouTube video or playlist, then select Load.
  2. For video search, playlist search, and playlist details, configure a YouTube Data API v3 key in Management · API connections. Select Save YouTube key and Test key. A direct video link does not need this key.
  3. Search songs or artists, search YouTube playlists, or choose a saved playlist and select Play. Use Previous and Next beside the player to navigate.

Use Search and Show queue below the video to open larger views with bigger images, text, and buttons. In search, select Search more to add the next page of video or playlist results. Close the view with Close or Escape. Search results and the playback queue are separate. Show playlist only hides search results; Clear queue empties the playback queue. Some videos cannot play embedded because of YouTube or owner restrictions.

10 · OUTPUT AND TV

Choose where sound plays

On Radio, Music, or YouTube, choose This browser or MyMusics host under Audio output. This browser uses the device showing the page; MyMusics host uses the audio device attached to the server.

If host output is unavailable, open Management · Test audio output. Select Check host audio tools and, if needed, Install or repair MPV and yt-dlp. Choose an output device, select Play test tone, then I heard it; use this output. YouTube host playback needs yt-dlp as well as MPV; its video remains visible in the browser while sound plays on the host. During startup, image and audio prepare together and wait for the host to be ready. Host audio follows browser pause, buffering, seeking, and playback speed; the app periodically corrects timing differences.

Use the TV mode control for the TV layout and remote navigation. In Management · Browser information, Emulate Silk lets you preview the TV layout on a computer.

11 · SAVED COLLECTIONS

Manage playlists and export saved data

Create local music playlists in Management · Playlists. Use Add to playlist on a music track to choose a destination.

In Management · Video playlists, create or choose a playlist, view its tracks, edit title, artist and genre, move videos to another playlist, or remove entries.

To import videos, paste individual YouTube video IDs or links, or choose a Chrome HTML, JSON, text, or CSV bookmarks file. Select Preview videos, check the entries to keep, then select Inlezen. A playlist bookmark alone does not supply its videos; use video-list JSON or load the YouTube playlist in the player.

Select Export JSON at the top of Management to download local Music playlists, YouTube playlists, and radio stations together.

TROUBLESHOOTING

Playback works, but a tool does not?

Radio playback and optional analysis are separate. If a stream blocks audio analysis, the equalizer or speech detection may be unavailable while playback still works. Track details, artwork, and lyrics also depend on metadata being sent and external services being reachable.
