Connect your Jellyfin library

Add these keys to /etc/mymusics/mymusics.env (or .env in the project root) and restart MyMusics.

JELLYFIN_URL=http://jellyfin.local:8096
JELLYFIN_API_KEY=your-api-key
JELLYFIN_USER_ID=your-user-id

Music mode reads the library and streams tracks through this server, so the API key never reaches the browser.
